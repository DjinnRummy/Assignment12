# Assignment 12 – Chapter 17: Big Data and SQL Queries

This repository contains the completed exercises for Chapter 17 from the textbook *Intro to Python for Computer Science and Data Science: Learning to Program with AI, Big Data and The Cloud*.

## Files

- `books.db`: SQLite database used for exercises
- `books.sql`: SQL file to build the database (loaded via `.read books.sql` in SQLite)
- `exercise_17_1_books_db_DYNAMIC.py`: Main Python script that performs queries and inserts data into the books database
- `exercise_17_2_cursor_fetch.py`: Script that prints titles table output using `fetchall()` and `description`
- `output.md`: Full runtime output from both scripts

## Notes
- `exercise_17_1_books_db_DYNAMIC.py` includes safe insert logic with `INSERT OR IGNORE` and error handling.
- See `output.md` for full runtime results and verification of operations.
